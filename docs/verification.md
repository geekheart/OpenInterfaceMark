## 代码审查修复

- 绘制手势固定形状类型，避免快捷键切工具产生无效项目。
- 方向预设约束标签坐标，避免大字号小图片产生不可重新导入的数据。
- 切换导出格式或关闭导出窗口使旧 PNG 任务失效。
- 宽字符标签使用保守边界，避免导出裁字。
- 导入或替换图片先取消当前拖拽，避免旧图坐标进入新图历史。
- 预览对象 URL 更新时释放，导出 URL 延迟释放；浏览器往返缓存保留有效预览资源。

尚未在 Firefox / Safari 或实机触屏上单独验证。本地子路径检查用于验证静态资源；线上版本以 Release 工作流和站点 version.json 为准。

- 输入框内 Cmd + Z 只撤销文字；帮助弹窗内快捷键不改动标注。

- `dist/` 的 `/OpenInterfaceMark/` 子路径加载新界面，撤销与帮助正常。390 px 窄屏下帮助窗口可滚动，窗口和文档无横向溢出。
- 10 项 Node 交互回归执行真实 app.js 注册的事件处理器，以轻量 DOM/指针捕获/坐标矩阵替身验证右键连续平移、组合按钮释放、多指针隔离、取消/失焦、拖动中撤销与删除保护、视图保持、输入与弹窗隔离、Space 和滚轮行为。没有复制交互实现或引入额外依赖。
