## English

- Adopt the MIT license and include its notice in the source and static release archive.
- Add a complete English README linked from the default Chinese README.
- Add Chinese / English switching and a direct `?lang=en` entry, covering the workspace, properties, shortcuts, image transforms, exports, errors and accessibility labels.
- Preserve the current design, user labels, filenames, undo history and canvas view when changing the interface language.
- Add a GitHub icon link in the header for quick access to the repository.
- Add localization regression tests. GitHub Actions deploys Pages and packages the same static build, with a SHA-256 checksum.

Images, fonts and project files continue to be processed locally in the browser, without a backend or remote font service.
