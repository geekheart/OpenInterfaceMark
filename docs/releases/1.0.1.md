## OpenInterfaceMark V1.0.1

浏览器内完成图片区域标注、引线排布和图片导出，无业务后端、文件上传或在线字体依赖。

[打开在线工作台](https://geekheart.github.io/OpenInterfaceMark/)

### 功能

- 导入、拖入或粘贴 PNG、JPEG、WebP 图片，使用矩形或椭圆标记区域。
- 编辑编号、标签、字号、文字与边框颜色；默认系统黑体，可加载本地 TTF、OTF、WOFF、WOFF2 字体。
- 拖动标签、引线起点和虚线折点，借助吸附辅助线对齐。
- 图片等比缩小、任意角度旋转；标注随图变换，文字保持水平。
- 导出 PNG、JPG、SVG，指定输出尺寸且只允许缩小；PNG/SVG 支持透明或白底，JPG 使用白底。
- JSON 保存与恢复图片、标注、本地字体和导出设置。
- Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做；右键拖动画布，支持复制、删除、微调、保存和缩放快捷键。

### 下载与使用

- `OpenInterfaceMark-V1.0.1-site.zip`：与 Pages 部署来自同一次构建的完整静态站点，解压后通过 HTTP/HTTPS 静态服务器访问。
- `SHA256SUMS.txt`：上述站点 ZIP 的 SHA-256 校验值。
- GitHub 自动提供 Source code ZIP / tar.gz；本地开发使用 Node.js 24、pnpm 11.19.0。

透明导出只移除画布背景，不自动抠除原图片中的白色。设计仅保存在当前页面内存中，刷新或离开前请下载项目 JSON。默认示例的六处框选为手工近似标注。

发布工作流先执行全部测试，再构建、部署 Pages，最后发布同一构建的 Release 附件。测试与浏览器检查范围见仓库 `docs/verification.md`。
